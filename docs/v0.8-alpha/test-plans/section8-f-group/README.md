## 2. 固定前提

**A → (A + C) → A′ → B′ ≠ B**

Canonical Aは、人間が選択・整理・承認した文脈および意図である。人間が再確認・承認したCanonical Aを、意図・権限・再拘束の正統な起点として扱う。AI生成の引き継ぎ文や変容した文脈には、その承認を自動継承させない。A′は媒介後の状態を識別する記号であり、承認された地位ではない。Canonical Aの変更とB′の最終採用は人間が判断する。

v0.7 Final ADOPTの本文・承認記録・承認状態・既存履歴は変更・再解釈・置換しない。

§8.3「run停止（Hard Abort）」は、既存§3.1のIdentity/governance failureに伴うgeneration/adoption cycle停止と同一範囲として人間承認済み。Tencent/Amapは独立した境界参考資料に限り、停止試験のPASS/FAIL根拠やαの有効性の証拠にしない。
